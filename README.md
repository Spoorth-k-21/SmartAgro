# 🌱 SmartAgro – AI-Based Smart Agriculture Assistant

SmartAgro is an AI-powered web application developed to assist farmers in making better agricultural decisions using Machine Learning and Deep Learning. The application recommends suitable crops based on soil and weather conditions, suggests appropriate fertilizers, and detects plant diseases from uploaded leaf images.

## ✨ Features

- 🌾 Crop Recommendation based on soil nutrients (N, P, K), pH, temperature, humidity, and rainfall.
- 🧪 Fertilizer Recommendation based on soil type, crop type, and nutrient values.
- 🌿 Plant Disease Detection using a CNN model trained on the PlantVillage dataset.
- 🌦️ Weather Integration for improved crop recommendations.
- 💻 Simple and responsive web interface for easy access.

## ▶️ How to Run Locally

1. Clone the repository.
2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser and visit:
   ```
   http://127.0.0.1:5000
   ```
